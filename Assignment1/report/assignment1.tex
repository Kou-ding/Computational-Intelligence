\section{Περιγραφή Συστήματος}
Επιλέγοντας ελεγκτή PI έχουμε:
\begin{equation}
    \label{eq:pi_controller}
    G_c(s) = K_P + \frac{K_I}{s} = \frac{K_P \cdot s +K_I}{s} = \frac{K_P(s+\frac{K_I}{K_P})}{s} = \frac{K(s+c)}{s}
\end{equation}

Γνωρίζοντας ότι το σύστημα με τον κινητήρα μας είναι:
\begin{equation}
    \label{eq:closed_loop_system}
    H(s) = \frac{25}{(s+0.1)(s+10)}
\end{equation}

Η συνάρτηση μεταφοράς ανοικτού βρόγχου προκύπτει ως εξής:
\begin{equation}
    \label{eq:open_loop_transfer_function}
    H(s)G_c(s) = A(s) = \frac{K(s+c)}{s(s+0.1)(s+10)}
\end{equation}

Καθώς έχουμε μοναδιαία αρνητική ανάδραση η συνάρτηση κλειστού βρόγχου μπορεί να υπολογιστεί από τη σχέση:
\begin{equation}
    \label{eq:closed_loop_transfer_function}
    H_c(s) = \frac{A(s)}{1+A(s)} = \frac{K(s+c)}{s(s+0.1)(s+10) + K(s+c)}
\end{equation}

Η βηματική ανάδραση του συστήματος κλειστού βρόγχου είναι:
\begin{equation}
    \label{eq:closed_loop_step_response}
    Y(s) = H_c(s) \cdot X(s) = \frac{H_c(s)}{s} = \frac{K(s+c)}{s[s(s+0.1)(s+10) + K(s+c)]}
\end{equation}

\begin{figure}[H]

Ένας ασαφής ελεγκτής FZ-PI (Fuzzy PI Controller) προσδιορίζεται από ασαφείς κανόνες της μορφής:
\begin{equation}
    \label{eq:fuzzy_rule}
    \text{IF } e(k) \text{ IS } A \text{ AND } \Delta e(k) \text{ IS } B \text{ THEN } \Delta u(k) \text{ IS } C
\end{equation}
,όπου τα A, B και C οι λεκτικές τιμές που αποδίδονται στα σφάλματα $e(k)$, $\Delta e(k)$ και $\Delta u(k)$ αντίστοιχα.

Στην προκειμένη περίπτωση οι λεκτικές τιμές των δύο εισόδων και της εξόδου παρουσιάζουν ίδιες συναρτήσεις συμμετοχής, όπως φαίνεται στο παρακάτω σχήμα:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{figures/fuzzy_rules.png}
    \caption{Λεκτικές Τιμές Εισόδων και Εξόδου Ασαφούς Ελεγκτή}
    \label{fig:fuzzy_rules}
\end{figure}

Οι βιβλιοθήκες της matlab που αυτοματοποιούν διαδικασίες ΣΑΕ δεν προορίζονται για ασαφείς ελεγκτές οπότε θα χρειαστεί να τροφοδοτήσουμε οι ίδιοι την μοναδιαία αρνητική ανάδραση. Εντάσσουμε τον controlled σύστημα του πρώτου σκέλους στο FIS μας, μέσω του οποίου επιδιώκουμε να βελτιώσουμε περαιτέρω τα χαρακτηριστικά του συστήματος μας.

\subsection{Fuzzy Inference System (FIS)}
To FIS μας έχει όλες τις παραμέτρους που προδιαγράφει η εκφώνηση της εργασίας όμως αξίζει να εστιάσουμε στην δημιουργία των κανόνων. Οι κανόνες δημιουργούνται με μια διπλή for loop η οποία περνάει όλες τις τιμές που μπορούν να πάρουν τα σφάλματα $e(k)$ και $\Delta e(k)$. Υπάρχουν τρεις υποπεριπτώσεις για τις οποίες προγραμματίζουμε διαφορετική συμπεριφορά:
\begin{itemize}
    \item \textbf{1η \& 2η Περίπτωση:} Όταν η διαφορά του σφάλματος είναι \textbf{μεγαλύτερη/μικρότερη} από το μηδέν, τότε το σύστημα μετριάζει την διόρθωση για να αποφύγει την ταλάντωση.
    \item \textbf{3η Περίπτωση:} Όταν η διαφορά του σφάλματος δεν σημειώνει κάποια μεταβολή, δηλαδή θεωρείται μηδέν, τότε το σύστημα ασκεί μια διόρθωση αντίθετη του τρέχοντος σφάλματος, ώστε να το οδηγήσει στο μηδέν.  
\end{itemize}

\section{Διαφορετικό Rule Base}
Εδώ παραθέτουμε τα αντίστοιχα αποτελέσματα, αυτή τη φορά για το Rule base που αναφέρεται στις διαφάνειες του μαθήματος. Είναι εμφανείς οι αυξημένες ταλαντώσεις, κατά την παρακολούθηση του σήματος αναφοράς, του συγκεκριμένου rule base. Παρά τις εντεταμένες ταλαντώσεις το σύστημα μπορεί και βελτιώνει τις παραμέτρους (overshoot, rise time) του γραμμικού ελεγκτή.
